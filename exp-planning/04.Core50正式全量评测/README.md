# 04. Core-50 正式全量评测

本目录用于整理已经冻结的 Core-50 数据集，并承接后续正式全量 benchmark 实验资产。

## 当前 Core-50

- 数据集数量：`50`
- 名单文件：`core50_datasets.csv`
- 简化路径表：`core50_dataset_paths.tsv`
- 校验报告：`validation_report.md`

## 后续计划

后续正式实验的内容建议继续放在本目录下：

- `params/`: 各算法固定超参数。
- `slices/`: 按机器或算法切分的任务 CSV。
- `launch/`: 远端启动脚本。
- `reports/`: 运行进度、失败修复和结果汇总报告。
