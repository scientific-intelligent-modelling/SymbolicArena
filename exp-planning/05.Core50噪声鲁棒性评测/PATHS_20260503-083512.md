## 快速核验命令

在 `iaaccn23` 上核验正式 state，不要匹配 dryrun：

```bash
cd /home/zhangziwen/workplace/scientific-intelligent-modelling
python - <<'PY'
import json
from collections import Counter
from pathlib import Path

base = Path("exp-planning/05.Core50噪声鲁棒性评测/generated/load_queue")
for sigma in ["sigma001", "sigma005", "sigma010"]:
    paths = [p for p in (base / sigma / "state").glob("*.state.json") if "dryrun" not in p.name]
    state = json.loads(sorted(paths)[-1].read_text())
    counts = Counter(t.get("state") for t in state["tasks"].values())
    print(sigma, dict(counts))
PY
```
