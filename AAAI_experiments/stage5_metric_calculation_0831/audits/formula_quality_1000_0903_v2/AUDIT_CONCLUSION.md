# 公式化简与等价裁决抽查结论

## 审计范围

- Ground Truth：SSR-50 的 50 条公式全部复核。
- 预测公式：从 6749 条可审计结果中抽取 1000 条。
- 条件分布：clean 336、noise001 334、noise005 330。
- 随机种子分布：520 为 332、521 为 336、522 为 332。
- 另有 1 条 `drsr::BPG9::s521::noise005` 因参数值无法解析而明确排除。

预测样本包含 292 条风险项，再以确定性分层方式补足 708 条。因此，本次结果适合发现问题，
但未经加权的比例不能解释为 6749 条总体上的错误率或通过率。

## 审计方法

- 使用非流式 `claude-opus-5` API，不调用 Claude Code。
- 模型输入不包含原化简结果、原等价裁决、算法、条件或排名。
- 首轮审计 1050 条；195 条触发独立二审和本地符号/数值复核。
- 二审中 52 条因严格 JSON schema 或一次超时失败，均执行一次格式重试；45 条恢复，7 条仍失败。
- 本地复核只把确定反例、严格非零证明和工件完全相同视为强证据。普通 SymPy
  `symbolic_difference_zero` 不能证明化简前后的定义域完全相同。
- 模型自报的 severity 仅留作证据；最终 severity 由离线规则计算。

## 主要结论

### Ground Truth

- 49/50 条化简保持了数值含义和精确定义域。
- `feynman-bonus.20` 的化简在共同定义域上代数相等，但消除了 `x2 = 0` 处原公式的
  奇点，扩大了定义域，因此不能视为精确语义保持。

### 预测公式化简

- `preserved`: 985
- `not_preserved`: 11
- `undetermined`: 4

11 条确认问题均属于化简消除分母、倒数或对数约束后扩大定义域。典型形式包括：

- `d2/(n + d2/d1)` 变为 `d1*d2/(d1*n + d2)`，新公式在部分 `d1 = 0` 点有定义；
- `A/(A + exp(t)/A)` 变为 `A**2/(A**2 + exp(t))`，新公式在 `A = 0` 有定义；
- 合并对数后允许原先非法的负变量取值。

### 相对 Ground Truth 的等价裁决

- `equivalent`: 160
- `not_equivalent`: 741
- `undetermined`: 99

与旧裁决相比：

- 18 条旧 `equivalent` 被确定性证据改判为 `not_equivalent`；它们全部来自 clean，主要是
  把近似系数、微小残差或近似周期常数当成了精确相等。
- 3 条旧 `equivalent` 仍无法确定。
- 3 条旧 `undetermined` 被新证据确定为 `not_equivalent`，属于覆盖恢复，不是旧错误。
- 98 条旧化简 `unable` 被确认至少保持了原表达式，属于覆盖恢复，不应算作冲突。

99 条未决项中有 92 条来自 gplearn，主要集中在极长表达式、空实数定义域、复数单位 `I`
或本地解析器不支持的结构。它们必须继续作为 abstention 单列，不能默认为正确或错误。

### 离线严重性

全部 1050 条：

- `pass`: 920
- `critical`: 12，其中 Ground Truth 1 条、预测公式 11 条
- `major`: 18，均为旧等价裁决被确定性证据推翻
- `minor`: 1
- `undetermined`: 99

`formula_audit_issues.jsonl` 共 172 条，它还包含重试恢复、覆盖恢复、本地解析失败等执行诊断；
172 不是公式错误数。确认的非 pass 项应按上面的 severity 分布解释。

## 调用与成本

- 早期预检：28 次。
- 首轮：1230 次，998 条成功冻结，52 条首轮失败。
- 二审：195 次，143 条成功冻结，52 条失败。
- 二审格式重试：52 次，45 条成功冻结，7 条失败。
- 总物理调用：1505/1575，剩余 70 次预算。
- 已知输入 token：5,501,342。
- 已知输出 token：2,550,654。
- 缓存读取和缓存创建 token：0。
- 按输入 3 元/百万、输出 15 元/百万、缓存读取 0.3 元/百万计算，已知用量成本为
  **54.763836 元**。

二审有 1 次 API timeout 没有返回 usage，因此总调用数完整，但 token 与成本统计缺少这一条；
54.763836 元应理解为已知用量成本，而不是保证覆盖供应商可能记录的超时计费。

## 建议

1. 在正式计算新六轴指标前，先修正或明确处理 `feynman-bonus.20` 的 Ground Truth 参考式。
2. 明确 SYM 的等价政策到底是“精确数学相等”还是“容差内数值相等”。本次按精确相等执行，
   因而不会把 `0.9999999999997*x` 与 `x` 判为等价。
3. 修复 11 条定义域扩大的化简结果，或在协议中明确改成“只要求共同定义域上的相等”；两种
   政策不能混用。
4. 对 99 条未决项保留 abstention，并优先补强复数常量、空实数域和超长 gplearn 表达式的
   解析与裁决规则。
