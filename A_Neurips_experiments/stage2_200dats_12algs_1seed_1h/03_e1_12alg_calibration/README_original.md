# 02 Candidate-200: 12-algorithm calibration

This folder freezes the Candidate-200 calibration stage. In the final paper chain, these results are used to choose the compact Probe-4 panel, not to select a Master-100.

Key files:

- `candidate200/stage1_candidate200_flat.csv`: final Candidate-200 list from dual-probe mining.
- `run_results/e1_12_dataset_algorithm_nmse_table.csv`: Candidate-200 × 12 algorithm calibration table.
- `probe4_selection/`: score tables and report for selecting DSO, PyOperon, iMCTS, and uDSR as Probe-4.
